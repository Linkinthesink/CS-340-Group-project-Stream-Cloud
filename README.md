# CS 340 Database Project
This database projects represents the culmination of 11 weeks of work to build Stream Cloud, a full-stack music-streaming database application. Stream Cloud is a database management system that is designed to organize and connect information about artists, albums, and tracks across multiple streaming platforms. 

** link to project: ** [http://classwork.engr.oregonstate.edu:9995/]

## How its Made:

** Tech Used:** 

Frontend: React, Vite, JavaScript, HTML, CSS

Backend: Node.js, Express

Database: MySQL / MariaDB
